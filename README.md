# UserSearch Bot — поиск, проверка и снайпинг юзернеймов Telegram

aiogram 3 · SQLAlchemy 2 (async) · Telethon · aiohttp · APScheduler · Telegram Stars

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # заполните BOT_TOKEN, ADMIN_IDS, API_ID/API_HASH
python bot.py
```

Таблицы БД создаются автоматически при первом запуске (`data/bot.db`).
Для PostgreSQL установите `asyncpg` и укажите `DATABASE_URL=postgresql+asyncpg://...`.

## Сессии для проверки (MTProto-пул)

Положите авторизованные Telethon-сессии (`*.session`) в папку `sessions/` и укажите
`API_ID`/`API_HASH` в `.env`. Аккаунты используются по кругу, попавшие во FloodWait
временно исключаются из ротации.

Без сессий бот работает в резервном режиме: проверка через t.me + Bot API + Fragment.
Это менее точно (не видны ники удалённых аккаунтов и зарезервированные), поэтому
для продакшена добавьте хотя бы 2–3 сессии.

## Как проверяется юзернейм

1. `t.me/<ник>` — быстрый фильтр явно занятых (экономит лимиты MTProto);
2. `fragment.com/username/<ник>` — торги / продажа / продан / привязан;
3. `account.checkUsername` через пул сессий — финальная проверка.

## Админка — `/admin`

Статистика, свои каналы ОП (бот должен быть админом канала), Tgrass и BotoHub (ключ, вкл/выкл, тест),
рассылка с кнопками и предпросмотром, управление пользователями (Premium, поиски, бан),
промокоды, глобальные настройки (лимит, кулдаун, поддержка, битва).

## Маски поиска

`C` — согласная, `V` — гласная, `D` — цифра, `*` — любой символ;
строчные буквы, цифры и `_` подставляются как есть. Пример: `neoCVC`, `CVCV_tg`.

## Доступ по тарифам

| Режим | Бесплатно | Premium |
|---|---|---|
| 6 букв | ✅ 1 поиск новичку + 2 за подписку на спонсоров | ✅ безлимит |
| 5 букв, маска, ловушка | — | ✅ |

Дальше — Premium или пакеты поисков за Telegram Stars. Количество бесплатных поисков
и бонус за подписку меняются в `/admin` → ⚙️ Настройки.

## Оплата

При покупке бот предлагает способ оплаты: ⭐️ Telegram Stars, 🦋 CryptoBot или 🚀 xRocket.
Цены в Stars — `PREMIUM_PLANS` / `SEARCH_PACKS`, в долларах — `PRICES_USD` (`config.py`).

- **CryptoBot** (Crypto Pay API) — счёт в USD, покупатель платит любой криптой. Токен: `CRYPTOBOT_TOKEN`.
- **xRocket** (Pay API) — счёт в USDT (фиат xRocket не поддерживает). Токен: `XROCKET_TOKEN`
  (приложение в @xRocket должно быть на API Version → Current).

Счёт живёт 1 час. Оплата начисляется автоматически: бот опрашивает платёжки каждые 30 секунд,
либо сразу по кнопке «✅ Я оплатил — проверить». Способ без токена в `.env` просто не показывается.

Поиск идёт, пока не найдёт свободный ник. Если свободных вариантов нет (узкая маска),
поиск не списывается.
