# NameHunter (UserSearch Bot) — поиск, проверка и снайпинг юзернеймов Telegram

aiogram 3 · SQLAlchemy 2 (async) · Telethon · aiohttp · APScheduler · Telegram Stars

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # заполните BOT_TOKEN, ADMIN_IDS, API_ID/API_HASH
python bot.py
```

Таблицы БД создаются автоматически при первом запуске (`DATA_DIR/bot.db`, по умолчанию `data/bot.db`).
Для PostgreSQL установите `asyncpg` и укажите `DATABASE_URL=postgresql+asyncpg://...`.

**Хостинг.** Все файлы бот пишет только в `DATA_DIR` — эта папка должна сохраняться при
перезапуске и обновлении. На Bothost это `/app/data` (бот запускается из `/app`, поэтому
значение по умолчанию `data` уже попадает туда).

## Аккаунты для проверки (MTProto-пул)

Укажите `API_ID`/`API_HASH` в `.env` и добавьте аккаунты в `/admin` → 🤖 Аккаунты: вход по
номеру или загрузка `.session`. Сессии хранятся в базе данных (таблица `mtproto_accounts`),
поэтому не пропадают при обновлении. Старые `.session` из `SESSIONS_DIR` при запуске один раз
переносятся в базу. Аккаунты используются по кругу, попавшие во FloodWait временно
исключаются из ротации.

Без сессий бот работает в резервном режиме: проверка через t.me + Bot API + Fragment.
Это менее точно (не видны ники удалённых аккаунтов и зарезервированные), поэтому
для продакшена добавьте хотя бы 2–3 сессии.

## Как проверяется юзернейм

1. `t.me/<ник>` — быстрый фильтр явно занятых (экономит лимиты MTProto);
2. `fragment.com/username/<ник>` — торги / продажа / продан / привязан;
3. `account.checkUsername` через пул сессий — финальная проверка.

## Админка — `/admin`

Статистика, свои каналы ОП (бот должен быть админом канала), Tgrass и BotoHub (ключ, вкл/выкл, тест),
рассылка с кнопками и предпросмотром, управление пользователями (Premium, поиски, бан),
промокоды, глобальные настройки (лимит, кулдаун, поддержка, битва).

## Маски поиска

`C` — согласная, `V` — гласная, `D` — цифра, `*` — любой символ;
строчные буквы, цифры и `_` подставляются как есть. Пример: `neoCVC`, `CVCV_tg`.

## Поиск по слову

Пользователь вводит слово (`crypto`) и получает до 5 свободных ников на его основе:
окончания (`cryptoly`), приставки (`getcrypto`), цифра вместо буквы (`crypt0`), подчёркивание
(`crypto_x`) и т. п. «Ещё варианты» продолжает с места остановки; если само слово занято —
можно сразу поставить на него ловушку. Варианты — `word_variants()` в `services/username_checker.py`.

## Ник в соцсетях

Раздел «🌐 Ник в соцсетях» в главном меню: проверка ника в Telegram, YouTube, X (Twitter) и TikTok,
поиск ника, свободного сразу везде (Premium), и ловушка с выбором сетей. Instagram без входа
в аккаунт не проверяется (отвечает 429) — для него только ссылка. Если сервер в РФ и в
`/admin` → 🩺 Проверка сервисов соцсети 🔴 — нужен `HTTP_PROXY`. Код — `services/social_checker.py`.

## Доступ по тарифам

| Режим | Бесплатно | Premium |
|---|---|---|
| 6 букв | ✅ 1 поиск новичку + 2 за подписку на спонсоров | ✅ до 25 ников в сутки |
| 5 букв, маска, слово, ловушка | — | ✅ |

Лимит Premium — найденных юзернеймов в сутки по Москве во всех режимах вместе
(`/admin` → ⚙️ Настройки, `premium_daily_limit`, по умолчанию 25, 0 — без лимита). Админы без лимита.

Дальше — Premium или пакеты поисков за Telegram Stars. Количество бесплатных поисков
и бонус за подписку меняются в `/admin` → ⚙️ Настройки.

## Оплата

При покупке бот предлагает способ оплаты: ⭐️ Telegram Stars, 🦋 CryptoBot или 🚀 xRocket.
Цены в Stars — `PREMIUM_PLANS` / `SEARCH_PACKS`, в долларах — `PRICES_USD` (`config.py`).

- **CryptoBot** (Crypto Pay API) — счёт в USD, покупатель платит любой криптой. Токен: `CRYPTOBOT_TOKEN`.
- **xRocket** (Pay API) — счёт в USDT (фиат xRocket не поддерживает). Токен: `XROCKET_TOKEN`
  (приложение в @xRocket должно быть на API Version → Current).

Счёт живёт 1 час. Оплата начисляется автоматически: бот опрашивает платёжки каждые 30 секунд,
либо сразу по кнопке «✅ Я оплатил — проверить». Способ без токена в `.env` просто не показывается.

Поиск идёт, пока не найдёт свободный ник. Если свободных вариантов нет (узкая маска),
поиск не списывается.

### Напоминание о продлении

За сутки до конца Premium (при коротком сроке — в последней четверти, напр. за 6 ч для 1 дня)
бот присылает напоминание с кнопками тарифов и скидкой на продление. Скидка задаётся в
`/admin` → ⚙️ Настройки (`renew_discount_pct`, по умолчанию 20%, 0 — без скидки), действует
до суток после окончания Premium, одноразовая и распространяется на Stars, CryptoBot и xRocket.
